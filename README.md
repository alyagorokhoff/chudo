# Чудеса «Подари чудо» — оригинальные исходники

Это сохранение оригинальных исходников пяти чудес проекта «К СЕБЕ» из приложенных архивов. Исходный код, изображения, шрифты, серверные маршруты, схемы, миграции, зависимости и конфигурации сохранены без изменений. Подготовка к новому размещению ещё не выполнялась.

| Чудо | Версия | Каталог |
|---|---:|---|
| Печенька с предсказанием | 11 | `01-pechenka/` |
| Монетка удачи | 11 | `02-monetka/` |
| Билет в маленькое приключение | 8 | `03-bilet/` |
| Объятие через экран | 5 | `04-obyatie/` |
| Бабочка благословения | 4 | `05-babochka/` |

Для каждого проекта файлы `VERSION.json`, `SOURCE_SHA256SUMS.txt` и `README_EXPORT.md` исходного архива находятся в его подкаталоге `archive-info/`. Контрольные суммы проверяются относительно файлов, размещённых непосредственно в каталоге чуда.
