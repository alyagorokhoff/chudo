# Билет в маленькое приключение · К СЕБЕ

Изолированный тестовый проект, не изменяет archangelsguide.ru и его репозиторий.

## Реализация
Vinext/React, Cloudflare Worker, постоянная база Cloudflare D1. Исходники `app/`, схема `db/schema.ts`, миграции `drizzle/`.
Результат назначается криптографически равновероятно (rejection sampling) в атомарном условном UPDATE. В БД — токен, тип, статус, задание, даты и SHA-256 приватного подтверждения. Приватное подтверждение создаётся до POST и хранится только на устройстве первого получателя. База обеспечивает одноразовость; localStorage используется для восстановления, не для запрета повторов.
GET/HEAD/OG не активируют подарок. У другого устройства нет подтверждения, поэтому оно получает только сообщение об использовании. После очистки браузерных данных восстановить билет невозможно: это сознательное следствие отсутствия регистрации.

`/test#<приватный ключ>` — закрытая функция генерации ссылок. Ключ хранится в runtime secret ADMIN_KEY, не в исходниках. Фрагмент удаляется из адресной строки после чтения. Для повторного входа нужна исходная приватная ссылка. API без ключа возвращает 403.

## Проверки
Успешная сборка; браузерный сценарий закрытый подарок → билет → отрыв нажатием → результат; PNG с naturalWidth 1080 и naturalHeight 1920; независимые кнопки и новый токен при отправке; вёрстка в контейнере 390 × 844; видимость брендового блока и действительный href.
`python checks/server.py`: опубликованный сервер, GET/HEAD не расходуют подарок, 12 параллельных получателей — один победитель, повторное получение запрещено, приватное восстановление сохраняет результат, недействительная ссылка 404, административные GET/POST без ключа 403, серверные OG-метаданные.

Не проверены на физических iPhone/Android и во встроенных браузерах Telegram/WhatsApp: жесты и системное сохранение/отправка требуют проверки на этих устройствах. Предусмотрены открытие одним нажатием, копирование ссылки и PNG через меню браузера. Изолированный тест раздаёт только билет; объединение пяти чудес и собственный основной домен — после утверждения.

Статистика: только типы событий и время, без персональных данных и сторонних трекеров.

## Единая упаковка при передаче дальше
GiftForward показывает общую сцену: бумага складывается, появляется бант, затем готовность подарка. Новая ссылка готовится параллельно, повторные открытия незавершённой отправки используют подготовленный подарок. Выбор получателя вызывается отдельным осознанным нажатием; при отсутствии системной отправки доступны копирование и ручной текст. Escape/закрытие возвращают к исходному чуду. Сохранение и серверная одноразовость не менялись.

## Сохранение картинок
Общий ImageSave показывает фактическую PNG-открытку, явное скачивание по нажатию и передачу файла через системное меню, а также сохранение долгим нажатием. card-image.ts загружает точный шрифт, изолирует заливки, рассчитывает переносы, фиксирует непрозрачный цвет букв и проверяет реальные тёмные пиксели в области текста до экспорта. У монетки PNG дополняет постоянную интерактивную ссылку.
