# Печенька с предсказанием · К СЕБЕ

Изолированная тестовая версия акции «Подари чудо». Не связана с рабочей веткой archangelsguide2_dont-touch, платежами, авторизацией или данными основного сайта.

## Архитектура
Vinext/React, Cloudflare Workers, отдельная постоянная D1 база. Схема и миграции в db/ и drizzle/. POST /api/gifts создаёт 256-битный криптографический токен; GET и предпросмотр не расходуют подарок. POST /api/gifts/:token атомарно выполняет UPDATE ... WHERE status='new'. Предсказание выбирается crypto.getRandomValues с rejection sampling для равной вероятности всех 30 вариантов.

Клиент до получения сохраняет отдельное 256-битное подтверждение. Сервер хранит только его SHA-256. Повтор запроса после сетевого обрыва с тем же подтверждением восстанавливает результат. Без подтверждения использованная ссылка возвращает только claimed, без текста предсказания. Подтверждение не включается в подарочную ссылку.

## Интерфейс
Подарок → печенька → разлом → автоматический разворот листа → предсказание. Этап вытягивания и торчащий фрагмент полностью удалены по просьбе пользователя. Поддержаны нажатие и жест двумя пальцами для разлома. Два 3D-сгиба раскрываются автоматически; повторные нажатия защищены блокировкой. Reduced motion сокращает переходы.

Итоговый экран распределяет свободное место по высоте viewport: интервалы между заголовком, листом, пояснением и кнопками увеличиваются на высоком экране; брендовый блок остаётся видимым снизу. Для длинного предсказания №29 в браузерной проверке 320×640 брендовый блок заканчивается на y=622, scrollHeight=640. Также проверены 390×720 и 390×840.

PNG 1080×1920 создаётся Canvas с настоящим Cormorant Garamond 400 и изображением печеньки. Прямое скачивание без Web Share; полноразмерное изображение, сохранение удержанием и явная ссылка скачать. Web Share используется только для нового подарка.

Дизайн основан на новом k-sebe-pearl-world: его жемчужный пейзаж и палитра #eee5e9 / #49384c / #51364f. Два растровых ассета cookie.png и gift.png созданы встроенным imagegen. Точный шрифт хранится локально, кириллица проверена. Серверные OG-метаданные не раскрывают содержимое подарка. Тестовый генератор доступен по отдельной непубликуемой ссылке.

## Передать тепло

Призыв: «Кому тебе сейчас хочется сделать приятно? Подари этому человеку маленькое чудо 🤍». Кнопка остаётся «Подарить чудо дальше». После нажатия — короткая универсальная анимация упаковки света в знакомый закрытый подарок; вид будущего чуда не раскрывается. Сервер создаёт отдельную одноразовую ссылку. Кнопка «Выбрать получателя» вызывает Web Share непосредственно из пользовательского нажатия. Отмена системного меню сохраняет готовую ссылку для повторной попытки внутри окна. Без Web Share предусмотрено копирование сообщения и ручное выделение при запрете Clipboard API. Чужим адресатам тестовые сообщения не отправлялись.

Сообщение: «Захотелось отправить тебе немного тепла 🤍\nВнутри — маленькое чудо. Интересно, какое достанется тебе?» — общее для будущих пяти чудес. В этой изолированной версии по-прежнему реализована печенька; остальные подарки не подключались. PNG 1080×1920 обновлён: более крупное предсказание, небольшая печенька, деликатная подпись «К СЕБЕ» и адрес. Проверены генерация и настоящее скачивание, размеры 320×640 / 390×720 / 390×840, окно упаковки, ручной резервный способ передачи и открытие новой ссылки без расходования.

## Первый вход без мелькания

Для новой ссылки сервер сразу отдаёт состояние подарка. После получения сервер выдаёт приватную HttpOnly SameSite=Lax cookie, ограниченную путём конкретного подарка; на HTTPS — Secure. Сервер сверяет её SHA-256 и сразу рендерит прежнее предсказание владельцу. Для старых ссылок с подтверждением только в localStorage проверка выполняется за нейтральным жемчужным фоном; GET восстанавливает cookie. Содержимое показывается одним плавным появлением после загрузки точного шрифта и изображений. Подтверждение не включается в ссылки, чужой браузер не получает предсказание. Ошибка связи больше не подменяется экраном нового подарка.

## Единая упаковка при передаче дальше
GiftForward показывает общую сцену: бумага складывается, появляется бант, затем готовность подарка. Новая ссылка готовится параллельно, повторные открытия незавершённой отправки используют подготовленный подарок. Выбор получателя вызывается отдельным осознанным нажатием; при отсутствии системной отправки доступны копирование и ручной текст. Escape/закрытие возвращают к исходному чуду. Сохранение и серверная одноразовость не менялись.

## Сохранение картинок
Общий ImageSave показывает фактическую PNG-открытку, явное скачивание по нажатию и передачу файла через системное меню, а также сохранение долгим нажатием. card-image.ts загружает точный шрифт, изолирует заливки, рассчитывает переносы, фиксирует непрозрачный цвет букв и проверяет реальные тёмные пиксели в области текста до экспорта. У монетки PNG дополняет постоянную интерактивную ссылку.
