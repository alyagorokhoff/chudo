# Объятие через экран · К СЕБЕ

Изолированное четвёртое чудо в ChatGPT Sites. Первые три проекта и archangelsguide.ru не изменяются.

## Реализация
Vinext/React + Cloudflare Worker; отдельная постоянная Cloudflare D1. Общие оригинальные файлы фона world.webp, закрытого подарка gift.png, OG и Cormorant Garamond Regular взяты из третьего чуда. Центральное жемчужное сердце создано imagegen, сохранено как public/heart-pearl.webp. Анимация — отклик на первое касание, удержание 1200 мс, полноэкранное объятие 7400 мс с объёмными складками, крупным пульсирующим сердцем и двумя последовательными тёплыми фразами, затем появление послания. Отдельная кнопка получения удалена по запросу автора. Только удержание сердца: палец/мышь или удержание Space/Enter. Reduced motion показывает спокойную сцену без движения в течение 3000 мс.

## Одноразовость
Криптографический токен 256 бит. Приватное подтверждение создаётся и сохраняется на устройстве до первого POST. Сервер хранит SHA-256 подтверждения. Назначение одного из четырёх текстов и смена created → claimed выполняются атомарным условным UPDATE … RETURNING в D1. Четыре исхода равновероятны: Uint32 % 4, без смещения. Повторный запрос владельца восстанавливает тот же результат. Остальные не видят чужую фразу. GET/HEAD/OG ничего не активируют. Очистка данных браузера удаляет подтверждение; без регистрации восстановление в этом случае невозможно.

## Проверка новых ссылок
`/test#<приватный ключ>`; ключ — runtime secret ADMIN_KEY. Тестовые операции недоступны без ключа (403). На странице обычного получателя нет тестовых элементов. Фрагмент удаляется из адресной строки после загрузки; для нового входа нужна исходная ссылка. Получатели не регистрируются и ничего не оплачивают.

Публичное создание ограничено 60 ссылками в час на анонимный хеш входящего IP, часового интервала и секрета. Исходный IP не сохраняется, устаревшие счётчики удаляются. Административная проверка без ограничения. Статистика — только тип события и время, без сторонней аналитики, персональных данных или секретных токенов.

PNG 1080 × 1920 создаётся в браузере с тем же посланием, общим фоном, сердцем, брендом и адресом. Размер текста подстраивается под фразу; предусмотрены download, системный share и открытие изображения для ручного сохранения. Отправка создаёт новый токен, копирование — запасной путь. Открытие системного меню не считается доставкой.

## Проверки
Сборка, точное совпадение четырёх текстов с ТЗ, точный файл шрифта и фона, мобильные контейнеры 390 × 700, 390 × 840 и 320 × 600 в Chrome, запуск после удержания 1.2 секунды, безопасный сброс короткого касания 0.35 секунды, удержание без кнопки обхода, восстановление результата при перезагрузке. Серверная проверка — checks/server.py.

На физических iPhone/Android, Safari и во встроенных Telegram/WhatsApp проверка не проводилась. Мобильная компоновка проверяется в Chrome, это не заменяет проверку реальных сенсорных устройств. Вибрация не требуется и не используется.

## Единая упаковка при передаче дальше
GiftForward показывает общую сцену: бумага складывается, появляется бант, затем готовность подарка. Новая ссылка готовится параллельно, повторные открытия незавершённой отправки используют подготовленный подарок. Выбор получателя вызывается отдельным осознанным нажатием; при отсутствии системной отправки доступны копирование и ручной текст. Escape/закрытие возвращают к исходному чуду. Сохранение и серверная одноразовость не менялись.

## Сохранение картинок
Общий ImageSave показывает фактическую PNG-открытку, явное скачивание по нажатию и передачу файла через системное меню, а также сохранение долгим нажатием. card-image.ts загружает точный шрифт, изолирует заливки, рассчитывает переносы, фиксирует непрозрачный цвет букв и проверяет реальные тёмные пиксели в области текста до экспорта. У монетки PNG дополняет постоянную интерактивную ссылку.
