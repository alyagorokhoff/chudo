# Бабочка благословения · пятое чудо «Подари чудо»

Размещается через тот же ChatGPT Sites / Vinext / Cloudflare Workers процесс, что и первые четыре чуда. Общее оформление, Cormorant Garamond Regular 400, world.webp, gift.png, og.png, PNG/share механика перенесены из существующего проекта. Прежние проекты не изменяются.

## Механика
D1 хранит gifts, events и временные бюджеты создания. При создании токен — 32 случайных байта, фраза — один из 8 вариантов, бабочка — одна из 5. Rejection sampling исключает смещение вероятностей. При явном POST open атомарный UPDATE WHERE status='created' закрепляет одного получателя. БД хранит только SHA-256 приватной квитанции; другой браузер получает used. GET/HEAD и OG не активируют подарок. GET /api/gifts?token=… возвращает только created/claimed без пары и без активации. /test публично создаёт новые тестовые подарки; 60 созданий в час на обезличенный временный ключ.

## Визуал
Пять отдельных изображений созданы встроенным imagegen: молочно-жемчужная с округлыми крыльями и тонкими шампань-прожилками; пудровая с заострёнными крыльями и светлыми овальными пятнами; сиреневая с длинными хвостиками и кружевным краем; сливовая с крупными светлыми пятнами и выраженными прожилками; шалфейная с веерообразными нижними крыльями. Файлы public/butterflies/*.webp, с прозрачностью, 900×900, около 190 КБ каждый. Общий prompt: straight overhead dorsal complete butterfly, centered vertical body, fully spread wings; fine silk-like natural scales, muted palette, transparent background, no text, flowers, icons, stars or glitter. Варианты различаются формой и рисунком, без CSS перекрашивания.

Левое и правое крылья двигаются независимо в перспективе. Касание сразу запускает движение к точке выше пальца, 1.7 секунды спокойного раскрытия крыльев, затем отлёт и результат; всего 3.6 секунды. Координаты ограничены внутри зоны и заданы процентами для адаптации при повороте экрана. Enter/Space работают через ту же бабочку. Reduced motion — спокойный переход за 2 секунды.

## Сохранение
Реальный PNG 1080×1920: та же бабочка, та же фраза, Cormorant, фон, «К СЕБЕ» и archangelsguide.ru. Поддерживаемая передача файлов через navigator.share; иначе загрузка, просмотр blob-изображения и ясная подсказка. Обе основные кнопки сохраняются. Новая подарочная ссылка создаётся отдельно. Тестовая версия передаёт дальше бабочку; подключение случайного выбора всех пяти чудес не меняет существующие проекты.

## Проверка
checks/server.py проверяет опубликованный API: безопасные GET/HEAD и предпросмотр crawler, 12 параллельных получателей, единственного владельца, сохранение пары при повторе/сетевом повторе, used для другого получателя, невалидную ссылку, новый подарок и серверные OG. Проверка интерфейса выполняется отдельно в Chrome на мобильных контейнерах 390×700, 390×840, 320×600. Физические iPhone/Android и реальные клиенты Telegram/WhatsApp не заявляются как протестированные.

## Единая упаковка при передаче дальше
GiftForward показывает общую сцену: бумага складывается, появляется бант, затем готовность подарка. Новая ссылка готовится параллельно, повторные открытия незавершённой отправки используют подготовленный подарок. Выбор получателя вызывается отдельным осознанным нажатием; при отсутствии системной отправки доступны копирование и ручной текст. Escape/закрытие возвращают к исходному чуду. Сохранение и серверная одноразовость не менялись.

## Сохранение картинок
Общий ImageSave показывает фактическую PNG-открытку, явное скачивание по нажатию и передачу файла через системное меню, а также сохранение долгим нажатием. card-image.ts загружает точный шрифт, изолирует заливки, рассчитывает переносы, фиксирует непрозрачный цвет букв и проверяет реальные тёмные пиксели в области текста до экспорта. У монетки PNG дополняет постоянную интерактивную ссылку.
