# Монетка удачи · К СЕБЕ — исходники версии 11

Действующая публикация: https://k-sebe-lucky-coin.alya-gorokhoff.chatgpt.site
Исходный коммит: b91cffab237b96315ecf1451211a0bbf0a7d5b4e

В каталоге source/ находятся ВСЕ 134 отслеживаемых файлов оригинального проекта именно этой опубликованной версии: интерфейс, анимации, изображения, шрифты, серверные маршруты, схема БД, SQL-миграции, зависимости и конфигурация сборки. Исходные файлы не изменены.

VERSION.json фиксирует происхождение, SOURCE_SHA256SUMS.txt содержит SHA-256 каждого исходного файла. При упаковке каждый файл дополнительно сопоставлен с его Git blob. README.md внутри source/ — оригинальный, в некоторых проектах сохранилось техническое название стартового шаблона; это не означает, что архив содержит лишь шаблон.

Это снимок последней сохранённой и успешно опубликованной версии на 25 октября 2026 года. Отдельное финальное утверждение пользователем именно этого номера версии не подтверждено. Не следует считать все замечания закрытыми лишь на основании публикации.

Архив не включает node_modules, результаты сборки dist, служебное состояние Git, локальные базы, секреты окружения и действующие данные подарков. Схема и миграции базы входят в исходники. Для запуска заново нужна установка зависимостей и привязка серверной базы DB; персональные данные и история уже выданных подарков сюда не переносились.

Это оригинальный полный серверный проект Vinext/React/Cloudflare D1, а не готовая статическая выгрузка для GitHub Pages. В этом шаге перенос и переработка не выполнялись. Действующие публикации и основной сайт не менялись.

В версии 11 монетки сохранение устроено через постоянную личную ссылку. Скачивание картинки монетки в интерфейсе удалено согласно последнему запросу пользователя; неиспользуемые исходные модули намеренно оставлены как в оригинальном коммите.
